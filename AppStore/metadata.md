# iDipper App Store 文案

## English (U.S.)
Name: iDipper
Subtitle: 7-Zip Archiver & Extractor
Promotional Text (≤170):
Open, browse and extract 7z, ZIP, RAR, TAR, ISO and 30+ formats. Dual-pane file manager, strong AES-256 encryption, hash checks and Finder integration.
Keywords (≤100):
7z,zip,rar,unzip,unrar,archive,extract,compress,tar,gz,iso,7-zip,decompress,file manager,encrypt
Description:
iDipper is a fast, powerful archive manager for macOS, powered by the proven 7-Zip engine.

• Open and extract 7z, ZIP, RAR, TAR, GZ, BZ2, XZ, ZST, ISO, DMG, CAB, WIM and 30+ more formats
• Create 7z, ZIP, TAR, GZ, BZ2, XZ and WIM archives with adjustable compression level, method, dictionary size and solid mode
• AES-256 encryption, including encrypted file names for 7z
• Split archives into volumes and join them back
• Dual-pane file manager: browse folders and archives side by side, copy and move with drag and drop
• Browse inside archives without extracting, drag files in and out
• Overwrite prompt when extracting: overwrite, skip, auto-rename or cancel
• CRC32, CRC64, SHA-1, SHA-256 and more hash checks
• Test archive integrity and run the built-in benchmark
• Finder Quick Actions: compress, extract here, extract to folder, checksum
• Favorites, folder history, keyboard shortcuts and native Mac menus
• Available in English, 简体中文, 繁體中文, 日本語, 한국어, Français, Deutsch, Español, Português, Italiano and Русский

iDipper includes 7-Zip by Igor Pavlov, licensed under GNU LGPL.

## 简体中文
名称：iDipper
副标题：7z / ZIP / RAR 压缩解压工具
推广文本（≤170）：
打开、浏览、解压 7z、ZIP、RAR、TAR、ISO 等 30 多种格式。双栏文件管理、AES-256 加密、哈希校验、访达右键一键压缩解压。
关键词（≤100 字节）：
压缩,解压,7z,zip,rar,解压缩,压缩包,tar,iso,加密,7-zip,归档,分卷
描述：
iDipper 是一款快速、强大的 Mac 压缩解压工具，基于久经考验的 7-Zip 引擎。

• 支持打开和解压 7z、ZIP、RAR、TAR、GZ、BZ2、XZ、ZST、ISO、DMG、CAB、WIM 等 30 多种格式
• 可创建 7z、ZIP、TAR、GZ、BZ2、XZ、WIM，压缩级别、方式、字典大小、固实模式均可调
• AES-256 加密，7z 可加密文件名
• 分卷压缩与合并
• 双栏文件管理器，文件夹和压缩包左右对照，拖放复制移动
• 不解压直接浏览压缩包内容，支持拖入拖出
• 解压时提示覆盖：覆盖、跳过、自动重命名或取消
• CRC32、CRC64、SHA-1、SHA-256 等哈希校验
• 测试压缩包完整性，内置性能基准测试
• 访达快速操作：压缩、解压到当前位置、解压到同名文件夹、校验
• 收藏夹、文件夹历史、快捷键、原生 Mac 菜单
• 支持简体中文、繁體中文、English、日本語、한국어 等 11 种语言

iDipper 内含 Igor Pavlov 的 7-Zip，遵循 GNU LGPL 许可。
