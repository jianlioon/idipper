iDipper bundles the official UnRAR utility to extract and test RAR archives,
including RAR5 methods that the bundled 7zz build cannot decode
(7-Zip reports them as v6:mN, for example v6:m3:1M, then fails with
"Unsupported Method" because this 7zz was built without the RAR codec).

Binary: UnRAR 7.23 arm64, taken from "RAR for macOS ARM 7.23"
https://www.rarlab.com/rar/rarmacos-arm-723.tar.gz
Only the freeware `unrar` executable is included. The trialware `rar`
compressor from that package is not distributed. iDipper does not create
or modify RAR archives.

The RAR trial license allows the UnRAR components to be distributed
separately from the rest of the package. The freeware license below is
the one that applies to this utility. It is copied from the UnRAR 7.2.3
source package (https://www.rarlab.com/rar/unrarsrc-7.2.3.tar.gz), which
is the source release corresponding to UnRAR 7.23. The acknowledgments
include the BSD license for the Intel Slicing-by-8 CRC32 code used by UnRAR;
that notice is required for binary redistribution.
